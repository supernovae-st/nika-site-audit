# Security Policy

This repository is a **legacy v0.79 demo workflow** (see the status
banner in the README — the syntax shown here predates the current
language). It is kept for historical reference and is not a supported
surface.

## Supported Versions

None — this repository is frozen legacy reference. Security fixes ship
in the [nika engine](https://github.com/supernovae-st/nika) on its
active branch.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub
issues, discussions, or pull requests.**

If something in this repository is actively harmful (e.g. a workflow
step that exfiltrates data when run verbatim), send an email to
**security@supernovae.studio** with the file and line. We acknowledge
receipt within **72 hours**.

For anything touching the engine or the current language, report it
against the engine repository's security policy instead.
